Apresenta os conceitos fundamentais que definem o que os computadores podem ou não podem resolver. O curso aborda três áreas principais: teoria dos autômatos, teoria da computabilidade e teoria da complexidade, que estudam respectivamente os modelos de computação, os limites do que pode ser computado e o nível de dificuldade dos problemas computacionais. 
Durante a aula também são revisados conceitos matemáticos essenciais, como conjuntos, funções, relações e grafos, que servem de base para entender os modelos teóricos de computação. São estudadas operações entre conjuntos (união, interseção, diferença e complemento), subconjuntos, conjunto potência, produto cartesiano e cardinalidade.
